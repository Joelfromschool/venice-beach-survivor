# Painted item sheets (optional)

Drop `art/items_<cat>.png` here and the game swaps it in automatically (no code change).
Each sheet: **4 columns of square cells**, transparent PNG, cells in the order below (row by row).
Cell art is drawn into the item's box in Pinco's 466x560 photo space (see `BOX` in index.html). Tints are applied with multiply.
